# ORBIT COURIER — 궤도 택배

[사이트 열기](https://hyungminyoon1.github.io/orbit-courier/)

발사 각도와 추진력을 조절해 중력원 옆을 지나 정거장에 배송하는 10구간 게임입니다.

- 행성 1~3개, 점점 작아지는 목적지, 같은 코드로 재현되는 항로.
- 캔버스 드래그·방향키·범위 조절기로 조준, Space로 발사.
- 비행 궤적 애니메이션, 일시정지·재개, 탭을 떠날 때 자동 정지.
- 충돌·이탈·시간 초과·배송 성공 판정, 직전 실패 궤적 비교.
- 성공 시 다음 구간 해금, 구간 선택, 항해 힌트, 기기 내 최고 점수.
- 생성 단계에서 유효한 도달 경로를 검증해 완료 가능한 목적지를 배치.

## 규칙과 저장 범위

고정 시간 간격으로 900×560 게임 공간을 계산하며 실제 우주 항법 시뮬레이터는 아닙니다. 성공 점수는 기본 1,000점에서 추진력·비행 시간·추가 시도·힌트 비용을 뺍니다. 힌트는 점수에서 120점을 줄입니다. 구간 해금은 기기에 저장되고 최고 기록은 항로 코드·구간별 최대 100개까지 보관합니다.

## 실행과 배포

Node.js 22 이상, 런타임 외부 의존성 없음.

```sh
npm run dev -- 0
npm test
npm run check
```

개발 서버는 loopback에서 `dist/`만 제공합니다. `main`에 푸시하면 고정 SHA Actions가 시험·정적 검사 후 `dist/`를 GitHub Pages에 배포합니다. 저장소 Pages의 배포 소스는 GitHub Actions입니다.

## 기록과 개인정보

기록은 이 브라우저에만 저장하며 삭제할 수 있습니다. 계정, 분석 도구, 외부 AI API, 클라우드 저장, 전체 사용자 랭킹은 구현하지 않았습니다. CSP가 런타임 외부 연결을 막습니다. 공개 저장소에 정답·게임 규칙이 포함되므로 시험/공식 경쟁 판정 시스템이 아닙니다.
